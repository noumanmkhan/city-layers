Toronto Layers

Toronto’s 158 neighbourhoods, 25 wards, 85 BIAs, old boroughs and the names locals actually use, like King West, live in a dozen separate city datasets. Toronto Layers puts them all on one map you can switch on and off. Type in any address to see every one it falls in.

Chicago Layers

The same map for Chicago: the nine sides, 77 community areas, 50 wards, Special Service Areas, the ‘L’ and Metra, and the neighbourhood names people actually use, like Wicker Park. Type in any address or place to see every boundary it falls in and who represents it.
